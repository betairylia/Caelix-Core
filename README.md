# Caelix Core

Caelix Core contains voxel data structures, streaming, ticking, and world persistence.

This package is an early research and development release.

Read the [documentation](Documentation~/index.md) for the
[storage model](Documentation~/internals/voxel-storage.md) and
[enumerator rules](Documentation~/reference/enumerators.md).

- [Caelix](https://github.com/betairylia/Caelix) — Custom voxel rendering & physics engine backend.
